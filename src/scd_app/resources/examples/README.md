# Bundled example recording

`emg.mat` is the 64-channel, 10-second test recording distributed with
[Swarm-Contrastive Decomposition](https://github.com/AgneGris/swarm-contrastive-decomposition),
copied from commit `8cd6153788b730383d6d6a1833ee99899ee5bcfb`.

- MATLAB variable: `emg`
- Shape: 102,401 samples × 64 channels
- Sampling rate: 10,240 Hz
- SHA-256: `ef0283ca7e541268c929d943e3a23df630fa9fb9566a714f82c80b36e615f17a`
- License: BSD-3-Clause

Run `scd-edition --example` to open it with the matching configuration.
