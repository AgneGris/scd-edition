# Support

Use the GitHub issue forms for installation questions, unexpected behaviour
and acquisition-format requests. Search existing issues first and include the
diagnostic information requested by the form.

Please never attach participant recordings or identifying metadata to a public
issue. A small synthetic example is usually enough to reproduce loader or GUI
problems.

Security-sensitive reports should not be filed publicly. Contact the maintainer
at `agnese.grison@outlook.it` with a concise description and reproduction steps.
